# CareerPath

CareerPath is a career guidance and opportunity discovery website designed for students and freshers.

## Live Website

[Open CareerPath Website](https://deekshithaprabu.github.io/CareerPath/)

## Source Code

[View CareerPath on GitHub](https://github.com/deekshithaprabu/CareerPath)

## Features

- Login and account creation
- Career assessment
- Career recommendation
- Personalized learning roadmaps
- Topic-specific learning resources
- Learning progress tracking
- Jobs and internship links
- Role-based opportunity links
- Responsive sage-green botanical design

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## Website Pages

| File | Description |
|---|---|
| `index.html` | Login and account creation |
| `dashboard.html` | Main dashboard |
| `assessment.html` | Career assessment |
| `learning.html` | Career learning roadmaps |
| `jobs.html` | Jobs and internship opportunities |

## Learning Roadmaps

The website provides learning paths for:

- Software Developer
- Frontend Web Developer
- Data Analyst
- Cybersecurity Analyst

Each roadmap contains:

- Important topics
- Learning resources
- Topic-specific links
- Progress tracking
- Practical project guidance
