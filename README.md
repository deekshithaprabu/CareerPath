# CareerPath

CareerPath is an career guidance and opportunity discovery website designed for students and freshers.

## Features

- Login and demo account creation
- Career assessment
- Career recommendation
- Personalized learning path
- Learning progress tracking
- Jobs and internship search
- Role-based job links
- Responsive sage-green botanical design

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## Pages

- index.html — Login and account creation
- dashboard.html — Main dashboard
- assessment.html — Career assessment
- learning.html — Learning roadmap
- jobs.html — Jobs and internships

## Future Improvements


- Live job API integration
- Student profile dashboard
- Resume builder
- Application tracking
